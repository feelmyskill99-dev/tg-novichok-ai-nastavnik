# Шаблоны outreach-сообщений

Заготовки для первого сообщения админу другого канала. Цель — короткое
честное сообщение, **без копипастного маркетинг-тона**.

Правило одно: пишем **как человек человеку**, без emoji-спама, без капса,
без «Здравствуйте! Меня заинтересовал ваш канал...». Это первая фраза
которая считывается как авто-рассылка.

---

## Template: `exchange`

Обмен аудиториями (взаимный анонс) с каналом сопоставимого размера.

```
Привет. Веду @ai_deposit_diary — дневник трейдера-новичка с маленьким
депозитом и AI-наставником, который не даёт нажать кнопку в эмоции.
Контент: разборы новостей, риск-менеджмент, ошибки без прикрас.

Аудитории, кажется, пересекаются с твоей. Подумал, что обмен анонсами
мог бы быть честным шагом для обоих. Один раз, без обязательств.

Если интересно — могу скинуть пример нашего поста. Если нет — без обид.
```

**Когда применять:** канал того же масштаба (±2x по подписчикам), такой же
тематики (обучение / новости без сигналов).

**Чего избегать:** не предлагать **деньги** за пост — это превращает в обычную
рекламу и ставит сразу в позицию слабой стороны.

---

## Template: `guest_post`

Предложение написать длинный полезный пост под их брендом.

```
Привет. Веду @ai_deposit_diary. Заметил, что ты регулярно поднимаешь
тему [КОНКРЕТНАЯ ТЕМА — например, риск-менеджмент / новичковые ошибки].

Могу написать гостевой пост на тему «[ПРЕДЛОЖИ ТЕМУ]» — ~1500 знаков,
без саморекламы внутри текста (можно подпись «материал подготовил
@ai_deposit_diary» в конце). Готовый текст пришлю на согласование,
правки твои.

Если откликнется — скажи, какой формат у вас работает лучше.
```

**Когда применять:** канал больше нашего (5-15k), у автора есть редполитика.
Шанс ответа меньше чем у exchange, но если согласится — пост остаётся
у них в ленте надолго.

## Template: `comments`

Не сообщение, а **поведенческий план**. На этот шаблон скрипт указывает,
если канал не отвечает на DM или у него нет публичных контактов.

```
Действие: подписаться на канал, под последними 10 постами оставить
содержательный комментарий (не «спасибо», а реальный разбор/вопрос).

Правила:
- Никаких прямых рекламных ссылок.
- Указываем своё авторство только через ник аккаунта владельца — НЕ
  через canned «А вот у нас на @ai_deposit_diary...» в каждом коммент.
- Цель — стать узнаваемым автором, чтобы любопытные сами зашли в профиль.
- Срок: 2 недели регулярных комментариев. После — оценка эффекта.

Метрика: количество новых подписчиков пришедших с канала X за период.
Если 0 за 2 недели — переходим к другому каналу.
```

**Когда применять:** канал крупный (10k+), личный DM не отвечает.

## Template: `cold_pitch_to_aggregator`

Холодный pitch в редакцию крипто-агрегатора (Bits.media, ForkLog, ProstoCoin).

```
Тема письма: «Гостевой материал — дневник трейдера-новичка с AI-разбором»

Здравствуйте.

Веду TG-канал @ai_deposit_diary — публичный лог обучения трейдингу
маленьким депозитом, с AI-разбором каждой сделки. Концепт: новичок без
прикрас + холодная вторая сторона (Claude).

За [N] месяцев в канале: [X] постов, [N1] детальных разборов реальных
сделок (с дневником эмоций), [N2] статей про риск-менеджмент.

Готов написать гостевой материал на одну из ваших регулярных тем —
например, разбор типичной ошибки новичка с конкретными цифрами из
своего лога. Объём 3000-5000 знаков, согласование вашей правкой.

Если формат подходит — пришлите шаблон / правила. Если нет — буду
читать вас дальше.
```

**Когда применять:** только когда в канале накопится ~30+ постов и есть
конкретные кейсы для ссылок. Для канала с 3 подписчиками рано.

---

## Чего НЕ писать ни в одном шаблоне

| ❌ Не использовать | Почему |
|---|---|
| «Здравствуйте! Меня заинтересовал ваш канал» | Авто-рассылочный паттерн, считывается за 0.5 сек |
| «Уникальное предложение для вас» | Маркетинг-щитом |
| Эмодзи в каждом абзаце 🚀🔥💎 | Сигналит «инфоцыган» |
| «Гарантирую X новых подписчиков» | Невозможно гарантировать |
| Готовый отформатированный пресс-релиз | Признак копипаста |
| Скриншоты статистики канала с 3 подписчиками | Слабо, лучше промолчать о размере |
| «Деньги за пост» в первом сообщении | Сразу превращает в рекламную позицию |
