# Задача: аудит post templates на однообразие

Проект: deposit_ai. Канал @ai_deposit_diary публикует ~2 поста в день,
все они проходят через Claude и стилевые гайды + Python-шаблоны.

**Проблема:** посты выглядят похожими друг на друга (одинаковая структура,
одинаковый порядок эмодзи-сносок 🐹→🤖→⚠️→📌, одинаковые концовки «Не финсовет...»).
Жалоба владельца — «канал как AI-свалка».

## Что нужно сделать

Прочитай 5 приложённых файлов и **верни ровно один markdown-документ** (не Python-код)
по такому формату:

```markdown
# Audit — post template uniformity

## Pattern 1: <название>
- **Где зашит:** `file.py:N-M` или `style_guide.md`
- **Симптом:** что именно делает посты похожими
- **Фикс (краткий):** одно предложение, что менять

## Pattern 2: <название>
(то же)

## Pattern 3: <название>
(то же)

## Что НЕ трогать
Перечисли 2-3 элемента, которые трогать НЕ стоит (работают как идентификаторы канала
или критичны для безопасности).
```

## Жёсткие правила

1. Не пиши код, не предлагай реализацию. Только аудит — что и где.
2. Не выдумывай файлы/функции — если чего-то нет в контексте, скажи «не вижу в контексте».
3. Каждый pattern должен ссылаться на КОНКРЕТНОЕ место (file:line или название гайда).
4. Не повторяй ТОП-3 совета, которые уже были даны выше (одинаковые заголовки / одинаковые эмодзи в одном порядке / одинаковые концовки) — найди ТРИ ДРУГИХ паттерна, более тонких. Например: одинаковые «связки» («И вот именно в такие моменты»), одинаковые HTML-теги, одинаковые длина абзацев, одинаковое использование RSI/EMA-метрик в каждом market-посте.
5. Ответ — один markdown-блок без `​`​`​`​markdown обёртки, чистый текст.
