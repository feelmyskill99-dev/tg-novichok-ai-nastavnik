# Задача: ревью контента канала @ai_deposit_diary

Ты — внимательный читатель крипто-TG-канала. Тебе показывают **28 опубликованных
постов за период 2026-04-26 → 2026-05-26**. Канал называется «дневник
трейдера-новичка + AI-наставник», 3 подписчика, целевой контент-микс
40% market / 20% news / 15% education / 15% author_notes / 10% trade_diary.

Файл с постами: `all_published_compact.json` (передан в контексте).
Поля каждого поста:
- `when` — datetime
- `kind` — news / market / author_note
- `sector` — подкатегория (ai_crypto / security_hacks_scams / stablecoins /
  regulation_etf_institutional / scam_radar / political_market_noise /
  fallback_education / market / macro)
- `title`, `source_title`
- `human` — голос «новичка» (только в news)
- `mentor` — голос AI-наставника (только в news)
- `text_excerpt` — превью market/author_note постов

## Что мне нужно от тебя

Верни **один Markdown-файл** (НЕ Python!) со следующими секциями. Будь
конкретным, цитируй посты по `#номер` или дате.

### 1. Точные дубли по смыслу

Найди посты в один и тот же день / соседние дни, которые **повторяют ту
же мысль** разными словами. Не похожие темы, а именно повтор.

Для каждой пары:
- какие посты (`#A` и `#B`)
- что повторяется (1 фраза)
- какой из двух удалить / переписать

### 2. Шаблонные фразы

Я уже заметил:
- `mentor_part` 11 раз начинается на «Стоп.»
- `human_part` 7 раз начинается на «Смотрю на заголовок» / «Читаю заголовок»
- «Разберём спокойно» — 2 раза подряд

Найди ещё 3-5 таких шаблонов (по тексту mentor/human). Для каждого:
- какой шаблон (точная цитата 3-6 слов)
- сколько раз встречается
- 3 альтернативных открытия в том же стиле

### 3. Чтение глазами читателя

Представь, что ты случайно зашёл в @ai_deposit_diary и листаешь хронологически.
Ответь **честно, кратко**:

- **Подпишешься ли после 5 постов?** (да/нет/может быть) и **почему**
- **Что цепляет** в этих 28 постах (конкретные посты по номерам)
- **Что отталкивает** (тоже конкретно)
- **Канал производит впечатление**: дневник новичка / новостная агрегация /
  спам партнёрки / что-то ещё?

### 4. Перекос по темам

Из 23 news-постов: 5 ai_crypto, 5 security_hacks_scams, 5 stablecoins,
4 regulation_etf. Это 19 из 23 (83%) — узкий регулятор+безопасность.

- Это норм для крипто-канала или перекос?
- Каких тем НЕ ХВАТАЕТ для дневника-новичка?
- Стоит ли понизить вес каких-то sector'ов в scorer'е?

### 5. Конкретные правки

Дай **5 конкретных правок** в порядке приоритета. Для каждой:
- **Что:** одно предложение
- **Где менять в коде:** примерные файлы (`news/analyzer.py`,
  `style_guides/` где-то, `bot.py` scheduler, etc — гадай по смыслу)
- **Why:** одна фраза «канал станет лучше потому что»

Не вдавайся в код-уровень. Это product-review, не PR.

## Чего НЕ делать

- Не предлагай удалять весь news-модуль / переписывать архитектуру
- Не пиши Python-код
- Не используй эмодзи в анализе (хотя в цитатах постов их можно сохранить)
- Не пиши длинных philosophical reflections — короткие фактические пункты

Один Markdown-блок ```markdown ... ``` без обрамляющего текста.
